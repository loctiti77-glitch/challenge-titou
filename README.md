# Challenge Titouan Taloc

Site du tournoi de foot en hommage à Titouan Taloc, organisé par l'association Les Amis de Titou.

Instagram : [@challenge_titou](https://www.instagram.com/challenge_titou/)

## Pages

| Fichier                 | Page               |
|-------------------------|--------------------|
| `index.html`            | Accueil            |
| `sponsoring.html`       | Dossier Sponsoring |
| `association.html`      | L'Association      |
| `premiere-edition.html` | La 1ère édition    |

Le style commun est dans `css/style.css`, les images dans `assets/`.

## Technologies

HTML et CSS uniquement, sans framework ni étape de build.

## Lancer en local

Ouvrir `index.html` dans un navigateur.

## Déploiement

Le site est hébergé sur Vercel. Chaque `git push` sur la branche `main` met le site à jour automatiquement.
